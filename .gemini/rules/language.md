# Language Preference Rule / Правило языка общения

- Пользователь общается исключительно на русском языке.
- ВСЕ ответы, документация, артефакты, планы реализации (`implementation_plan.md`), описания изменений (`walkthrough.md`) и пояснения ДОЛЖНЫ составляться строго на РУССКОМ языке.
- Не использовать английский язык для планов реализации и сообщений.
