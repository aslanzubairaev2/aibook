# Инструкции Claude

Работай по общим правилам из [`AGENTS.md`](AGENTS.md). Claude Cloud работает только в своей
ветке или worktree, не изменяет `main` и передаёт результат через commit и handoff-файл.

Перед началом проверь состояние ветки. Не трогай незакоммиченные изменения, которые не относятся
к твоей задаче.
