# Инструкции Claude

Работай по общим правилам из [`AGENTS.md`](AGENTS.md). Claude работает в своей ветке или
worktree. Закончив и проверив задачу, спроси владельца «Залить сразу в `main`?» — при «да»
заливай в `origin/main` по порядку из раздела «Git-контракт» в `AGENTS.md`, без PR и без споров.

Перед началом проверь состояние ветки. Не трогай незакоммиченные изменения, которые не относятся
к твоей задаче.
