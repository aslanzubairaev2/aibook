# Архитектурные решения координации

## 2026-08-28 — Git как общий протокол агентов

- Claude Cloud и Gemini Local работают в отдельных ветках.
- Codex выполняет координацию, review и проверки через Git diff, commits, PR и Preview.
- `main` считается production-веткой и не предназначен для прямой работы агентов.
- Перед production используется интеграционная ветка `staging` при необходимости.
- Передача контекста хранится в `docs/coordination/handoffs/`, один файл на ветку.

## Как добавлять решение

Новые решения добавляет координатор после согласования. Формат: дата, заголовок, решение,
причина и затронутые области.
