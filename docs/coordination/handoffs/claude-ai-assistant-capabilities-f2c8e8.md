# Handoff: «Обсудить с AI» — свободный чат вместо шаблона

- Агент: Claude
- Ветка: `claude/ai-assistant-capabilities-f2c8e8`
- Статус: закоммичено в ветке, в `main` не мержено

## Проблема

Владелец: чат «как запрограммированный алгоритм» — на любой вопрос «комментарий +
4 предложения-примера + 3 чипа». Пример: «покажи все слова с räumen» → четыре
предложения вместо списка слов. Причины:

1. Системный промпт навязывал одну форму ответа на каждом ходу («каждый пример —
   целое предложение», «4–6 примеров», «ровно 3 чипа»), а на follow-up всё равно
   присылал шаблон первого разбора «для справки».
2. Модель — `gemini-3.1-flash-lite` с `thinkingBudget: 0`.
3. История передавалась склеенной `join("")` без переводов.

## Что изменено

- `lib/ai/buildDiscussPrompt.ts`: на follow-up (кроме homework) — блок
  «FREE CONVERSATION TURN»: делать ровно то, что просят (полный список слов,
  анекдот/история/диалог, квиз, проверка предложения, «как сказать»), без
  обязательной формы. Блок WHAT TO COVER и «4–6 примеров» отправляются только на
  первом разборе. Чипы — 0–3, разных видов, пустой список лучше филлера.
  `learning`-часть может быть одиночным словом.
- `app/api/ai/discuss/route.ts`: история — построчно, с переводами; thinking
  budget только для `discussModel` (фолбэк остаётся без мышления).
- `lib/config.ts`: `discussModel` → `gemini-3.8-flash`,
  `discussThinkingBudget: 1024`, `discussMaxOutputTokens` 4096 → 6144.
- `DiscussAiModal.tsx`: если модель не вернула чипы, фиксированный стартовый
  набор больше не подставляется.

## Проверка

- Живые вызовы Gemini (ключ из `.env.local`) на трёх запросах владельца,
  flash-lite/3.8 без мышления/3.8 с 1024: все три следуют просьбе с новым
  промптом; 3.8 без мышления ошиблась в фактах (einräumen «неотделяемый»),
  3.8+1024 — лучший ответ, 2–3,3 с. Первый разбор на 3.8+1024 — 3,6 с,
  finish=STOP.
- `npm test` 461/461, `tsc --noEmit` чисто. ESLint-ошибка `react-hooks/refs`
  в `DiscussAiModal.tsx:240` была и в HEAD до изменений.

Вернуть `discussModel: "gemini-3.1-flash-lite"` и `discussThinkingBudget: 0` —
новый промпт и на ней даёт списки/анекдоты, но с фактическими неточностями.
