# Handoff: спряжения без ежедневного «всё подряд»

- Агент: Claude
- Ветка: `claude/verb-conjugation-mechanics-2ac752`
- Статус: ready-for-review

## Проблема

Тренажёр «Глаголы» каждый день предлагал все глаголы, ещё не пройденные сегодня, а «Спряжения» —
6 полей на каждое выбранное время. Прогресс хранился один на слово, поэтому «Формы» и «Спряжения»
делили общий результат. Таблицы для Präteritum/Perfekt/Futur каждый раз запрашивались у ИИ как полная
матрица из ~70 фраз (8192 токена), а локальный кэш грамматики держит всего 150 записей на всё
приложение, поэтому таблицы вытеснялись и запрашивались заново.

## Сделано

- `lib/verbConjugation.ts` — спряжение на устройстве из сохранённых форм: Präteritum, Perfekt
  (`haben/sein` → принимаются оба), Futur; Präsens для слабых и смешанных глаголов. Учтены trennbare
  и возвратные глаголы, основы на -t/-d/-chn/-tm, -s/-ß/-z, -eln/-ern. Если правило не уверено,
  возвращается null и используется ИИ.
- Ключевые лица (`keyPersons`): у сильных в настоящем — du+er, у особых — все (wir/sie, совпадающие
  с инфинитивом, заблокированы), у слабых и в Perfekt/Futur — одно случайное лицо. Галка «Все 6 лиц».
  После ошибки показывается вся таблица времени.
- Проверка спряжения строгая (`exact`): `besucht` ≠ `besuchst`, `fahrst` ≠ `fährst`; `ae/oe/ue` и
  `ss` вместо `ß` засчитываются. «Формы» строги только к умлауту.
- `lib/db/local.ts` — отдельное хранилище форм по глаголу (`aibook_verb_conjugation`, до 4000
  записей): ответ ИИ запрашивается один раз на глагол и время.
- `lib/srs/drillSchedule.ts` — своё расписание FSRS для каждой пары (глагол, режим/время), счётчики
  ошибок по режимам, план сессии (просроченные первыми, потом новые, лимит 10/20/40/все,
  по умолчанию 20). «Незнакомые/Сложные» выбирают конкретные режимы, а не слово целиком; пока у режима
  нет истории, используется старое состояние слова.
- Повтор ошибок в той же сессии не сдвигает срок. Подсмотренный ответ засчитывается полосе пачки,
  но режим возвращается завтра.

## Проверки

- `npm test` — 560 passed
- `npx tsc --noEmit` — passed
- `npm run build` — passed
- eslint по изменённым файлам — только 3 старые ошибки (`VerbsView.tsx:131` set-state-in-effect,
  `local.ts:181/198` no-explicit-any)
- Вживую на localhost:3100: пачка из 10 глаголов × 3 времени — 30 карточек, к ИИ ушло 2 запроса
  (настоящее время `kommen`, `schreiben`), всё остальное открылось мгновенно; формы сверены вручную;
  повтор ошибок не меняет сроки; после сессии пачка показывает «На сегодня всё», а общая кнопка —
  «Тренировать 20 из 123».

## Риски

- Прогресс хранится локально на устройстве, как и раньше; расписание на телефоне и компьютере не
  синхронизируется.
- Первые дни все режимы считаются «новыми», поэтому за сессию берётся по 20 глаголов, пока не
  наберётся история.
- Режим «Блиц» (60 секунд, случайные ячейки) не делался — оставлен на потом.
