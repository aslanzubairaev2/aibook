## Сделано

### 1. Быстрый просмотр форм по удержанию слова

Долгое удержание (телефон) или правая кнопка (компьютер) на любом иностранном
слове открывает компактную плавающую подсказку: перевод, две формы прошедшего и
спряжение в настоящем времени единственного числа для глагола; артикль и
множественное число для существительного. Подсказка прижимается к краям экрана
и уходит порталом в `document.body` — иначе внутри 3D-трансформации карточки
тренажёра `position: fixed` отсчитывался бы от карточки, а не от экрана.

Скорость достигнута не выбором модели, а отказом от неё: `gemini-3.1-flash-lite`
и так самый быстрый тир. Немецкая морфология считается локально за 0 мс —
слабое спряжение выводится правилами, сильные глаголы выписаны таблицей
(~160 строк), приставочные производные выводятся из базы (`aufstehen` → `stehen`
→ `stand auf` / `aufgestanden`).

**Про риск выучить неверную форму.** Ошибиться модуль может ровно одним
способом: просклонять как слабый сильный глагол, которого нет в таблице. Такие
ответы помечаются `provisional`, и UI их не показывает вовсе — вместо
возможной ошибки стоит «уточняю формы…» до ответа модели. Полнота таблицы
проверяется тестом на контрольной выборке (`germanVerbs.test.ts`), а не
обещанием в комментарии. Формы, сохранённые в словарной статье, перекрывают
любой вывод по правилу.

В сеть уходит один запрос вместо трёх (`/api/ai/quick-word` вместо
`translate` + `noun-forms` + `verb-forms`): 160 токенов, `temperature: 0`,
кэш в localStorage на 400 слов.

Заодно исправлено: в списке «на сегодня» слова были мёртвым текстом — теперь
они такие же живые, как в списке «Все».

### 2. Словарь не перечитывается при каждом переключении экрана

Экран словаря и экран карточек читают один снимок из кэша сессии. Внутри
минуты возврат не ходит в сеть вовсе; за её пределами список остаётся на
экране, а запрос уходит фоном. Удаление слова или пачки обновляет снимок.

Отдельно: эффект в `CardsView` зависел от объекта `user`, а Supabase отдаёт
новый объект на каждом обновлении токена — то есть словарь перечитывался ещё и
при каждом переключении вкладки браузера. Теперь зависимость от `user.id`.

Первая загрузка рисует каркас списка вместо кружка посреди пустоты.

### 3. Главная — про изучение слов, а не витрина книг

Полки Gutendex убраны целиком (два внешних запроса при каждом открытии
приложения ради книг, которые не читают). Вместо них: сегодняшнее повторение,
три тренажёра с реальными числами и распределение артиклей с указанием самой
слабой группы. Всё считается из локальных данных — ни одного сетевого запроса,
работает офлайн.

Приложение теперь всегда открывается на главной. Место в книге не теряется —
оно стало строкой «продолжить»; синхронизация между устройствами не тронута.

### 4. Обложки грузятся по мере прокрутки

Обложки были `background-image`, а фон нельзя пометить `loading="lazy"` —
открытие каталога тянуло все обложки страницы разом. Новый `BookCover`:
цветная подложка с первого кадра плюс `<img loading="lazy" decoding="async">`
поверх. Применено в классике, аудиокнигах и на полке библиотеки.

### 5. Оформление

Главная и «Практика» переведены с одинаковых «плашек» (иконка + надпись +
заголовок + подпись + стрелка) на строки под мелким заголовком раздела.
Громкий элемент на странице ровно один.

### 6. Модель обсуждения

`gemini-3.7-flash` → `gemini-3.1-flash`. Прежняя отвечала заметно медленнее и
дороже, а разницы в качестве разбора слова это не окупало. Промпт не менялся.
Опустить до самой быстрой можно переменной окружения:
`NEXT_PUBLIC_GEMINI_DISCUSS_MODEL=gemini-3.1-flash-lite`.

## Риски и продолжение

- Таблица сильных глаголов покрывает ~160 базовых слов. Глагол вне таблицы и
  вне «подозрительных» финалей (`STRONG_LIKE_RIMES`) получит слабые формы без
  пометки. Пополнять таблицу — самый дешёвый способ сузить этот зазор;
  контрольную выборку в тесте стоит расширять вместе с ней.
- Ложные срабатывания охранной проверки («stimmen», «fehlen», «lieben»,
  «mieten») стоят одного ожидания при первом просмотре, дальше слово в кэше.
- Локальная морфология только для немецкого. Для других целевых языков
  подсказка целиком приезжает из сети — работает, но не мгновенно.
- Окно свежести словаря (60 с) выбрано на глаз. Если фотографии слов
  добавляются с другого устройства, изменения увидятся не сразу.
- Stitch MCP подключить не удалось: сервер не сконфигурирован в этой сессии, а
  для подключения нужен API-ключ владельца. Оформление сделано вручную.
- Не сделано: серверная предвычисленная подборка для главной — после удаления
  книг с главной она стала не нужна.
