# Handoff: управление глаголов (предлог + падеж) и новая карточка слова

Ветка: `claude/verbs-prepositions-cases-920e90`

## Что сделано

- Управление глагола хранится в `dictionary_entries.forms.rektion` строкой вида
  `mit + Dat (с кем); über + Akk (о чём)`. Разбор и курированный список ~160 глаголов —
  `lib/verbGovernment.ts`. Строки без поля берут значение из списка.
- Миграция `20261022180000_verb_government.sql` (данные, без DDL) применена к проду:
  101 из 133 глаголов получили `rektion`; 32 оставшихся — без дополнения (schlafen, können…).
- Новые глаголы получают `rektion` при сохранении (`normalizeDictionaryEntryDraft`), без ИИ.
- `GermanVerbSummary.government` → показывается: в карточке слова (блок «Предлог и падеж»
  после форм), на обороте флешкарты (строка под формами), в таблице «Глаголы» под переводом
  (скрывается вместе с формами в режиме самопроверки).
- Карточка слова переделана: без рамок вокруг секций, формы — строки «название → значение»,
  слово набрано Lora, действия — один список.

## Проверки

- `npm test` 603/603, `npx tsc --noEmit`, `npm run build` — зелёные.
- Визуально проверено на временной странице с реальными компонентами (375px).
- В залогиненном приложении (реальные карточки/таблица глаголов) — см. отчёт в сессии.

## Риски

- Списки управления курированы вручную; глаголы вне списка покажут управление только если
  его заполнит пользователь или будущий промпт ИИ.
- `npm run lint` падает на старой ошибке `VerbsView.tsx:136` (set-state-in-effect), не от этой задачи.
