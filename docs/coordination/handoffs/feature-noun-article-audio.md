- Commits: `ef368fd`, `0acbfd3`

## Сделано

- В тренировке существительных добавлены варианты подсказки для режима «Артикль»:
  изучаемый язык, родной язык, аудио и «Всё» (три варианта вперемешку).
- Аудиоподсказка автоматически запускается при появлении вопроса, а повторный запуск остаётся доступен кнопкой.
- В TTS передаётся только `bareNoun` без `der/die/das`; браузерный и серверный кеш разделены namespace `noun-article`, поэтому общий кеш слов с артиклем не переиспользуется.
- Кнопка озвучивания в таблице существительных также передаёт только `bareNoun` и использует тот же namespace.
- Настройки презентации сохраняются локально рядом с настройками режимов существительных.
- Для пустых переводов добавлен backfill через существующий AI-маршрут дозаполнения существительных и отдельный блок «Без перевода».
- Промпт и PATCH словаря расширены переводом, при этом существующий перевод никогда не перезаписывается.

- `lib/ttsCacheScope.test.ts` — проверка namespace-нормализации.

## Риски и продолжение

- Нативная подсказка пропускается для записи без перевода; экран показывает такие записи в «Без перевода» и предлагает дозаполнение через AI.
- Для каждого нового голоса/модели namespace остаётся частью server-side `voice_name`, поэтому отдельная миграция базы не требуется; старые записи общего кеша продолжают работать как раньше.
- Живая проверка самого квиза через браузер требует авторизованного словаря; build, типы и unit-тесты пройдены.
