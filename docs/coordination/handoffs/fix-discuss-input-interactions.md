## Сделано

- Один общий QuickWordPreview для правого клика на кликабельных словах видео, чата, AI-панели, примеров слов, читалки, упражнений и аудиокниг. Контекст и язык передаются атрибутами без изменения разметки управления.

- Портал подсказки находится внутри fullscreen-элемента, координаты ограничены экраном.
- Совместимый click после long-press подавляется; движение отменяет long-press.
- Кнопки примера чата перенесены в правую колонку: одинаковые 40 px по ширине, минимум 44 px по высоте и растяжение на высоту примера.
