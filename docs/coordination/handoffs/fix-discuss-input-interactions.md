Переход с одноязычного Web Speech API на передачу аудио в Gemini заблокирован auto-review до явного согласия пользователя на отправку записей микрофона. Код диктовки пока не изменён.

## Сделано

- Один общий QuickWordPreview для правого клика на кликабельных словах видео, чата, AI-панели, примеров слов, читалки, упражнений и аудиокниг. Контекст и язык передаются атрибутами без изменения разметки управления.
- Подсказка по правому клику закрепляется до Escape/клика вне её; hover только для мыши с задержкой 1 сек. Устаревшие асинхронные ответы игнорируются, запросы одного слова объединяются, локальный/общий кэш сохраняется.
- Портал подсказки находится внутри fullscreen-элемента, координаты ограничены экраном.
- Совместимый click после long-press подавляется; движение отменяет long-press.
- Кнопки примера чата перенесены в правую колонку: одинаковые 40 px по ширине, минимум 44 px по высоте и растяжение на высоту примера.
- Выделение слов останавливает видео, родительский click после drag подавляется. Повтор не запускает поставленный на паузу плеер. Горячие клавиши видео отключены при открытом разборе выделения.
