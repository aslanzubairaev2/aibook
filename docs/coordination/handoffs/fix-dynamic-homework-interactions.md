# Handoff: динамические интерактивы для словообразовательных упражнений

- Агент: Codex
- Ветка: `fix/dynamic-homework-interactions`
- Commit: `3431a25`
- Статус: ready-for-review

## Сделано

- Добавлен универсальный тип домашнего задания `formation`: AI передаёт исходные слова и список требуемых полей ответа, а UI строит одну общую модалку по этой конфигурации.
- Для упражнения «Образуйте от глаголов существительные, обозначающие лица, переведите их на русский язык» отображаются четыре исходных слова; по нажатию открывается модалка с полями «Существительное» и «Перевод».
- Сохранены ответы, расчёт прогресса и печать/PDF для динамического числа полей.
- Старые сохранённые упражнения, которые были ошибочно распознаны как `conjugation`, автоматически перенормализуются в `formation`, если инструкция явно просит существительные, обозначающие лиц.
- Усилен prompt и JSON-schema извлечения: словообразование больше не должно маршрутизироваться в спряжение; поддержаны женская форма, множественное число, перевод и другие поля без создания отдельного компонента для каждого задания.

## Изменённые области
