## Границы задачи

Пользователь разрешил передачу записей микрофона Google для распознавания. Заменён только механизм диктовки в «Обсудить с ИИ». Дизайн реплик и кнопок примеров Claude, чужие изменения и production не изменялись.

## Сделано

- Браузерный SpeechRecognition с фиксированным языком заменён записью по кнопке → mono PCM WAV 16 kHz → сервер → `gemini-3.5-transcribe`.
- Автоматическое определение языков, verbatim-режим, максимум 80 слов текущей реплики как контекст. История чата не отправляется.
- Максимум 60 секунд, остановка и отмена, остановка при закрытии/смене контекста/уходе со вкладки.
- Текст дописывается в черновик; автоотправка сообщения удалена. Ошибки не стирают черновик.
- Проверка доступа через существующий serverAuth, проверка WAV/размера до вызова Google; ключ остаётся на сервере (или используется ключ, введённый пользователем).
- Один запрос без автоповтора. Inline audio и `store:false`; нет сохранения аудио в базе/логах приложения или Files API.
- Видимый статус/ошибки и счётчик отправленных секунд за день на устройстве. Это оценка, не биллинг Google.

## Риски и продолжение

- Проверить реальную речь пользователя на телефоне: синтетическая проверка не гарантирует качество для произношения, шума и конкретного устройства.
- `store:false` не отменяет правила обработки/хранения данных Google.
- Отмена после отправки не гарантирует отмену списания квоты. Нет автоматических повторных отправок или смены модели.
- Модель проверена в списке моделей проекта и реальным запросом 31.08.2026. Ключ другого пользователя может не иметь доступа.
- Safari/Android: MediaRecorder выбирает доступный формат, затем Web Audio преобразует в WAV; проверка на реальных устройствах ещё нужна.
- Реальные секреты, аудио и чужие generated-файлы исключены из коммита.
