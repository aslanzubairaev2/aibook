# Handoff: референсный экран аналитики и реальный CEFR

## Что сделано

- Восстановлен экран по референсу: AIBook в шапке, только кнопка звонка и Live перевод, компактная индиго/фиолетовая карточка уровня и четыре исходных метрики.
- Уровень больше не берётся из прочитанных книг и не выводится из общего размера колоды.
- Текущая лексическая зона вычисляется по явным `card.cefr` у уникальных слов; суффикс `+` появляется только при закреплении текущей зоны по SRS (`intervalDays >= 15`, без lapse).
- В интерфейсе разделены уникальные слова в базе и общее количество карточек SRS.
- Метрики главного экрана используют реальные поля карточек: долгосрочная память (`>=15` дней), доля просмотренных карточек без lapse и книги/уроки из профиля.
- Модальное окно сохранено и дополнено интервалами, тремя направлениями обучения и структурой материалов.
