## Сделано

- Применена и проверена миграция `dictionary_batches.page_label` в production Supabase.
- Исправлены пересечения ответов у частей с одинаковым печатным номером (`3a`, `3b`, `3c`).
- Упражнения на распределение слов переведены в выбор из банка: выбранные слова отображаются чипами, использованные блокируются и становятся серыми.
- Для задания «две активности к каждому времени года» добавлена реконструкция рядов, сохранение готового примера и выбор незаполненной категории.
- Словарь, найденный по ссылке на страницу, теперь объединяется с распознанным банком слов для сортировочных упражнений.

- `components/homework/*` — независимые ключи ответов и интерактивный picker слов.
- `lib/ai/buildHomeworkPrompt.ts` — нормализация частей упражнений и структуры сортировки.
- `lib/ai/lessonModel.ts` — схема `sortRows` для AI.
- `app/api/lessons/from-homework-image/route.ts` — передача слов словаря в сортировку.
- `app/page.tsx` — восстановление новых ответов при открытии домашнего задания.
