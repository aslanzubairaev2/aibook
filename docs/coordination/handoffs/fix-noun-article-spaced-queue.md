## Сделано

- Повторные задания по одному существительному распределяются по сессии с сохранением порядка режимов для самого слова.
- Та же логика применяется при повторе ошибок. При единственном оставшемся слове пауза между его заданиями физически невозможна.
- Пока ученик отвечает, подготавливается аудио для аудиозаданий среди четырёх следующих вопросов, строго по одному запросу за раз. Используются существительное без артикля и отдельный кеш `noun-article`.
- Устранена гонка параллельных предзапросов одного слова: второй запрос присоединяется к первому до проверки кеша; все фоновые запросы проходят через общую последовательную очередь.
- В режиме артиклей клавиши `8` / `5` / `2` выбирают `der` / `die` / `das` (цифровой ряд и NumPad, также с выключенным Num Lock).
- При ошибке Gemini тренировка больше не подменяет выбранный голос другим провайдером или голосом браузера; сообщение об ошибке видно на карточке. Резервная модель Gemini сохраняет то же имя голоса.
- В Gemini TTS передаётся явный код языка в `speechConfig.languageCode`, например `de-DE`. Старые записи Gemini с потенциально ошибочным произношением исключены из нового ключа кеша.
- На аудио- и визуальной карточках артикля есть «Переозвучить»: `respeak` принудительно обновляет запись без артикля в отдельном кеше.
- Подсказка в настройках больше не обещает показывать все режимы одного слова подряд.
