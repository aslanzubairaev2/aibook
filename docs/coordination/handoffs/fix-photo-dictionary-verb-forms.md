## Сделано

- Исправлен контракт structured output для фото-импорта словаря: у каждой записи теперь обязателен объект `forms`.
- Внутри `forms` Gemini обязан вернуть `praeteritum`, `partizip2`, `hilfsverb` и `trennbar`; для не-глаголов используются пустые строки, для немецких глаголов — реальные формы.
- Обязательными также стали поля классификации и примера, включая `partOfSpeech` и `contentType`.
- Добавлена регрессионная проверка схемы ответа, чтобы модель снова не могла пропустить формы глагола.
