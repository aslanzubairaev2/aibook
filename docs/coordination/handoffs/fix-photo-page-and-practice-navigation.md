# Handoff: обязательная страница пачки и безопасный выход из практики

- Агент: Codex
- Ветка: `feature/ai-verb-phrase-tutor`
- Commit: `39fda47`
- Статус: ready-for-review

## Сделано

- Для пачек, создаваемых фотографированием слов, добавлено отдельное поле `page_label`.
- Номер страницы/урока обязателен в форме фото и проверяется повторно на API; пачка без него не создаётся.
- Старые пачки читаются с резервным извлечением страницы из `kind`/описания и могут быть исправлены через редактирование пачки.
- Автоматический подбор словаря для домашнего задания использует `page_label` и старые поля как fallback.
- Выход из практики глаголов и существительных теперь ведёт в общий список практики.
- Убраны переходы с `setState` прямо из JSX-рендера, которые могли вызывать циклический рендер при пропавшей книге/уроке.
