## Сделано

- Для известных вспомогательных и модальных глаголов формы возвращаются из проверенного словаря приложения без вызова Gemini; ошибочные ответы модели для этих слов исправляются перед сохранением.
- Для остальных глаголов используется экономичная модель с адекватным лимитом ответа и заголовками авторизации пользователя.
- Умная пачка требует все четыре формы каждого немецкого глагола, отклоняет обрезанный ответ до записи и создаёт отдельную пачку даже при повторе темы.
- После сохранения слов ошибка создания карточек возвращается как предупреждение, а не как ложная ошибка создания пачки. Описание показывает фактическое число обработанных слов.

- Имеющиеся неполные записи нужно один раз дозаполнить кнопкой «Дозаполнить все»; пользовательские данные не менялись автоматически.
