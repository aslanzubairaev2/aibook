## Сделано

- Кнопки действий скрыты у неактивных реплик; у активной реплики действия находятся над текстом, а отдельная Play/Pause-кнопка — справа.
- Добавлены быстрый tooltip по правому клику на компьютере и long-press на телефоне; tooltip не включается обычным hover на touch-устройствах.
- Убрано стандартное выделение отдельных слов видео, сохранено выделение нескольких слов через drag с остановкой видео.
- Словарная модалка получила крупные кнопки озвучивания, обсуждение слова/примера и открывается поверх текущего AI-чата; закрытие возвращает чат.
- В примерах убрана нумерация; пример можно одним нажатием отправить в текущий чат для подробного разбора.
- История чата теперь строится из актуального ref, чтобы старое первое сообщение не возвращалось в каждый следующий запрос.
- Для голосового ввода добавлен bias распознавания по словам текущей немецкой фразы и несколько альтернатив; базовый язык остаётся языком пользователя.
- Для разделяемых глаголов добавлено восстановление инфинитива по частице в конце предложения, например `wacht ... auf` → `aufwachen`.

## Риски и продолжение

- Web Speech API поддерживает один основной язык за сессию; grammar bias улучшает смешанные русско-немецкие фразы, но не заменяет специализированное мультиязычное распознавание аудио.
- Глубокие три формы глагола в tooltip показываются только если они уже присутствуют в кэше анализа; полная таблица по-прежнему открывается через модалку грамматики.
