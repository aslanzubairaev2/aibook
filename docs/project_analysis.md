## 1. Концепция и назначение приложения

**AIBook** — mobile-first PWA для изучения иностранных языков (основной фокус — немецкий, также английский, французский, испанский и др.) через чтение книг, прослушивание аудио, интерактивный разбор текста, интервальное повторение (SRS SM-2) и AI-тьютора (Google Gemini).

### Ключевые сценарии пользователя:
1. **Чтение с мгновенным AI-ассистентом**: Тап по любому слову → перевод, грамматическая форма, артикль, род, примеры употребления, добавление в словарь/SRS.
2. **Аудиосопровождение (Karaoke TTS)**: Озвучка предложений и абзацев с синхронной подсветкой слов.
3. **Каталог текстов и книг (Discover)**: Чтение классики (Project Gutenberg), детской энциклопедии (Klexikon), уровневых текстов (CEFR A1–C2), пользовательских уроков.
4. **Интервальные карточки (SRS)**: Тренажер слов и фраз по алгоритму SM-2 (распознавание, активный ввод, аудио-диктант).
5. **Грамматика и глаголы (Verbs)**: Справочник основных форм глаголов (Präsens, Präteritum, Perfekt) + 4 интерактивных квиза.
6. **LiveChat с Gemini Live**: Голосовой диалог с AI в реальном времени.
7. **OCR и генерация уроков**: Фото страницы учебника/книги → автораспознавание → интерактивный урок.

## 2. Технологический стек и архитектурные принципы

- **Фреймворк**: Next.js 16 (App Router) + React 19 + TypeScript 6.
- **Стилизация**: Чистый Vanilla CSS (`styles/globals.css`, `modal.css`, `panel.css`, `reader.css`).
  - *Никакого Tailwind или CSS-модулей*. Все классы глобальные, переиспользуемые.
  - *Dark Theme*: Базовый фон `#141210`, акцентный золотой `#d4a847`, фон плашек `#1f1c18`, границы `#2e2a24`.
  - *Mobile-First*: Максимальная ширина контейнера `max-width: 640px`, центрирование на десктопе, поддержка `env(safe-area-inset-*)`.
- **База данных и синхронизация**:
  - **Offline-First**: Книги и тяжелый контент хранятся в IndexedDB (`lib/db/local.ts`), настройки и прогресс — в `localStorage` с префиксом `ns:<userId|guest>:`.
  - **Облако**: Supabase (PostgreSQL, Row Level Security, Auth, Storage). Мгновенная гидратация из локального кэша → тихий фоновый sync.
- **Управление состоянием**:
  - Без Redux/Zustand. Единый корневой контекст `AuthProvider` (`lib/auth/useAuth.tsx`).
  - Состояние страниц живёт в `app/page.tsx` и передается пропсами.
  - Для TTS используется отдельный pub/sub store (`lib/tts.ts`, `subscribeTTS`).
- **AI и LLM**:
  - Google Gemini (`gemini-3.1-flash-lite` — базовая, `gemini-3.7-flash` — обсуждения и анализ).
  - Промпты генерируют строгий JSON (`lib/ai/build*.ts`), устойчивый парсер с починкой JSON (`lib/ai/jsonResponse.ts`).

## 3. Карта экранов и существующих компонентов

### Главный роутер и навигация:
- `app/page.tsx` — Центральный координатор приложения (SPA-навигация через стейт `AppSection`).
- `components/ui/AppShell.tsx` — Внешний каркас с нижней панелью навигации (Bottom Nav: Главная, Каталог, Книги, Читалка, Карточки, Глаголы, Настройки).

### 1. Каталог и исследование (`components/discover/`):
- `DiscoverView.tsx` — Экран каталога с 5 подвкладками:
  - `classic`: Классическая литература Gutenberg через Gutendex API.
  - `klexikon`: Статьи детской немецкой энциклопедии Klexikon.
  - `cefr`: Адаптированные тексты по уровням A1–C2.
  - `lessons`: Сгенерированные AI-уроки и домашние задания.
  - `dictionary`: Тематические наборы слов (пачки) для тренировок.
- `BookDetailModal.tsx` — Карточка книги: обложка, метаданные, 4-строчный AI-обзор ("О чем", "Жанр", "Язык/CEFR", "Кому"), интерактивный чат с AI о книге (`aiChat`), кнопка загрузки/чтения.
- `LessonComposerModal.tsx` / `LessonRefineModal.tsx` — Создание и редактирование AI-уроков.
- `DictateButton.tsx` — Кнопка голосового ввода через Web Speech API.

### 2. Читалка (`components/reader/`):
- `ReaderView.tsx` — Ядро читалки:
  - Токенизация слов (`lib/selector/text.ts`).
  - Интерактивный клик/тап по слову.
  - Выделение фраз и предложений drag-жестом.
  - Karaoke TTS: подсветка читаемого предложения и слова.
  - Сохранение точного скролла и параграфа.
- `components/ai-panel/AiPanel.tsx` — Выдвижная нижняя панель (bottom-sheet) с подробным грамматическим и семантическим разбором выделенного слова/фразы.
- `components/word-modal/`:
  - `WordModal.tsx` — Быстрое модальное окно слова: перевод, транскрипция, формы, озвучка, кнопка «В карточки».
  - `GrammarModal.tsx` — Таблицы склонений/спряжений (артикли, падежи, времена).
  - `ReverseWordModal.tsx` — Обратный перевод и контекстные примеры.

### 3. Обсуждение с AI (`components/discuss-ai/`):
- `DiscussAiModal.tsx` — Полнофункциональный AI-тьютор для глубокого обсуждения слова, фразы, предложения или упражнения:
  - Режимы `word`, `phrase`, `sentence`, `homework`.
  - Быстрые подсказки-вопросы (Quick Prompts: *"Как сказать я..."*, *"Примеры из жизни"*, *"Скажи проще"*).
  - Голосовой ввод вопросов.
  - Кнопки добавления примеров в SRS и открытия грамматических таблиц.

### 4. Карточки и интервальное повторение (`components/cards/`):
- `CardsView.tsx` — Управление колодами, фильтрация по частям речи, уровням CEFR, статусам обучения (новые, на изучении, повторение).
- `Trainer.tsx` / `ActiveTrainer.tsx` — Режимы тренировки: прямое распознавание (DE → RU), обратное (RU → DE), аудио-диктант, активный ввод с клавиатуры.

### 5. Глаголы (`components/verbs/`):
- `VerbsView.tsx` — Таблица 100+ базовых сильных и неправильных немецких глаголов (Infinitiv, 3. Person, Präteritum, Partizip II, Hilfsverb).
- `VerbsQuiz.tsx` — 4 интерактивных режима квизов на формы глаголов.

### 6. Живой голосовой чат (`components/livechat/`):
- `LiveChatModal.tsx` — Прямой полнодуплексный голосовой диалог с Gemini Live через WebSocket.

## 4. Механика интерактивности текста и слов

1. **Токенизация**:
   - `lib/selector/text.ts` разбивает текст на токены с сохранением пунктуации и пробелов.
   - Каждое слово оборачивается в интерактивный `<span>` со специальными data-атрибутами.
2. **События тапа и выделения**:
   - Одиночный тап → мгновенное открытие `WordModal` или `AiPanel`.
   - Зажатие и протяжка (Drag) → выделение предложения/фразы.
3. **TTS Karaoke**:
   - `lib/tts.ts` координирует воспроизведение через выбранный провайдер.
   - Посылает события `word_highlight` и `sentence_highlight` в UI читалки.

## 5. Дизайн-система и токены (`styles/globals.css`)

```css
:root {
  --bg-primary: #141210;     /* Основной темный фон */
  --bg-elevated: #1f1c18;    /* Фон карточек и модалок */
  --bg-hover: #2a2621;       /* Фон при наведении */
  --border: #2e2a24;         /* Основные границы */
  --border-strong: #453e35;  /* Выделенные границы */
  --accent: #d4a847;         /* Золотой акцентный цвет */
  --accent-soft: rgba(212, 168, 71, 0.15);
  --text-primary: #f0e6d3;   /* Основной светлый текст */
  --text-muted: #9c9284;     /* Вторичный приглушенный текст */
  --radius-sm: 8px;
  --radius-md: 12px;
  --radius-lg: 16px;
}
```

### Цвета уровней CEFR:
- **A1**: `#4caf50` (Зеленый)
- **A2**: `#8bc34a` (Салатовый)
- **B1**: `#2196f3` (Синий)
- **B2**: `#03a9f4` (Голубой)
- **C1**: `#9c27b0` (Фиолетовый)
- **C2**: `#673ab7` (Глубокий фиолетовый)

### Генерация динамических обложек:
- Функция `pickColor(title: string)` генерирует стабильный детерминированный градиент из палитры `COVER_COLORS` для книг без обложек.

## 6. Матрица повторного использования компонентов (Reusability Matrix)

> ⚠️ **КРИТИЧЕСКОЕ ПРАВИЛО:** Не создавать компоненты-дубликаты, если функционал уже реализован в кодовой базе.

| Задача | Существующий модуль / компонент | Как переиспользовать |
| :--- | :--- | :--- |
| **Обсуждение книги / текста с AI** | `lib/ai/chat.ts` (`aiChat`), модальные паттерны `BookDetailModal.tsx`, `components/discuss-ai/DiscussAiModal.tsx` | Использовать единый endpoint `/api/ai/chat` и проверенный UI диалога с историей сообщений. |
| **Оценка и разбор книги через AI** | `lib/ai/chat.ts` + промпт 4-строчного резюме | Переиспользовать функцию `splitReview` и CSS класс `.ai-review-card`. |
| **Отображение обложек и заглушек** | `pickColor(title)` + `<img loading="lazy">` | Использовать одинаковый fallback на SVG-градиент с инициалами. |
| **Фильтры по языкам и уровням CEFR** | `DiscoverView.tsx` (`CEFR_COLORS`, пилюли фильтров) | Использовать те же CSS классы `.filter-pill`, `.cefr-badge`. |
| **Голосовой ввод вопросов** | `components/discover/DictateButton.tsx` | Встраивать готовый компонент кнопки микрофона. |
| **Кнопка озвучки (TTS)** | `components/ui/SpeakButton.tsx` | Озвучка отдельных слов и фраз. |
