# «Личные местоимения» в Практике — для преподавательского агента

С 2026-10-20. Тренажёр выбора личных местоимений (Nominativ + Akkusativ) и коротких предложений:
`Ich sehe dich. Seht ihr uns? Könnt ihr sie abholen? Wir warten auf euch.` Два вида заданий: люди
(«Они видят нас» → Sie sehen uns) и замена существительного (die Tasche → sie — род по немецкому слову).

## Устройство

| Что | Где |
|---|---|
| Каталог глаголов, местоимений, существительных, блоков и уровней | `lib/pronouns/catalog.ts` |
| Настройки и их проверка по каталогу | `lib/pronouns/config.ts` |
| Построение заданий, сессия, адресные повторы | `lib/pronouns/tasks.ts` |
| Покомпонентная проверка ответа (правила, без модели) | `lib/pronouns/check.ts` |
| Событие истории (`training_events`, trainer `pronouns`) | `lib/pronouns/record.ts` |
| Статистика, навыки, отсроченные повторы, пробелы | `lib/pronouns/stats.ts` |
| Хранилище: настройки, назначенные сессии, пересмотр оценок | `lib/pronouns/store.ts`, миграция `20261020120000_pronoun_practice.sql` |
| UI | `components/pronouns/*`, ссылка преподавателя `/practice/pronouns/<id>` |

Задания строятся только из каталога. Задание попадает в сессию, только если включены **все** нужные ему
блоки: отделяемый глагол требует `separable` даже в задании с существительным, `warten` — `prep_auf`.
Возвратные местоимения и Dativ не включаются (Dativ — заготовка в каталоге, `case: dative` отклоняется).

## Режимы и проверка

- `choice` — выбор местоимения (используется после ошибки для адресного разбора), `gaps` — пропуски
  (сначала одно местоимение, потом оба; глагол дан), `written` — перевод письменно, `spoken` — голосом
  (Web Speech API браузера).
- Компоненты: `subject`, `object`, `conjugation` (согласование с тем подлежащим, которое выбрал ученик),
  `sentence_type`, `word_order`, `government`, `separable_prefix`, `negation` (отрицание и смысл),
  `spelling`. «Er sieht euch» на «Они видят нас» — две неверные роли и правильно согласованный глагол.
  Перепутанные роли («Wir sehen sie») — одна путаница (`error_kind: role_swap`).
- Принимаются ae/oe/ue/ss, любая пунктуация и регистр; вынесенное вперёд дополнение («Uns sehen sie»).
  В письме sie/Sie в середине предложения — смысл; в речи регистр распознавателя не учитывается.
- Незнакомое проверке слово или ответ без глагола → `needs_review`: ученик может исправить или отправить
  на проверку. В ошибки такой ответ не идёт.
- Неуверенное распознавание (confidence < 0.55) и сбои микрофона → `technical`, в статистике отдельно.
  При сбое микрофона задание можно перевести в письменное — оно записывается как письменное.

## История

Каждый ответ — событие в общей `training_events`: `trainer: "pronouns"`, `checks: "pronoun"`, `mode` —
режим ответа, `word` — глагол, `pronoun` — `подлежащее>дополнение`. В `meta`: `task_id`,
`template_version`, конструкции, целевые подлежащее/дополнение (лицо, число, род, падеж, форма),
ожидаемые формы, вердикт по каждому компоненту, путаницы, разбор, `correction_of` (исправление указывает на
первый ответ — первый ответ никогда не заменяется), `delayed_review` / `recheck_of` / `followup_of`,
`assigned_session_id`, `active_ms` (без времени распознавания), `speech` (транскрипция, уверенность),
`check_method`. Ссылки на аудио нет: браузерное распознавание запись не хранит; показатели
произношения не измеряются (поле предусмотрено).

## Инструменты MCP

- `get_training_summary` / `get_training_history` с `trainer: "pronouns"` и фильтрами `case`,
  `response_mode`, `construction`, `verb`, `role`, `pronoun` (uns, euch, sie_plural…; голое «sie»
  неоднозначно и игнорируется). Сводка получает блок `pronouns`; события — `event_id` и `pronoun_task`.
- `get_learning_gaps` → `pronoun_practice`: повторяющиеся путаницы в первых ответах с основанием
  («В 3 первых ответах использовано euch вместо uns в роли дополнения»); одиночные — отдельно,
  «недостаточно для вывода».
- `get_pronoun_practice_config` — настройки, каталог, ограничения, назначенные сессии.
- `update_pronoun_practice_config` — включить пройденные блоки, глаголы, режимы.
- `create_pronoun_practice_session` — назначить сессию; возвращает ссылку; тот же `client_key` не создаёт
  дубликат.
- `submit_pronoun_answer_review` — исправить автоматическую оценку; оригинал и все ревью сохраняются,
  сводка считает последнее.
