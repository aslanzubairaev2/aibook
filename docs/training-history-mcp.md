# История тренировок через MCP — для преподавательского агента

С 2026-10-03 каждый ответ в тренажёрах AIBook записывается как событие. Раньше хранились только
агрегаты: расписание SM-2 у карточек (`get_progress`) и счётчики по словам в браузере. Старая история не
восстанавливается и не придумывается.

## Что хранилось до этого (аудит)

| Тренажёр | На сервере | Локально (браузер) | Через MCP до сих пор |
|---|---|---|---|
| «Повторение» (карточки) | SM-2: повторения, интервал, ease, срок, последний повтор; по трём направлениям | — | `get_progress`, `list_flashcards` |
| «Активно» | — | SM-2 по навыкам (вспомнить/слушать/сказать) | ничего |
| Артикли и существительные | — | счётчики пачек, статистика по окончаниям | ничего |
| Формы глаголов и спряжения | — | счётчики пачек | ничего |
| Предлоги, прилагательные | — | счётчики пачек | ничего |
| Тесты | всё | — | `get_assessment_results`, `get_learning_gaps` |

Теперь все тренажёры дополнительно пишут события, а агрегаты остаются как были. Вторую систему прогресса
это не создаёт.

## Событие

| Поле | Значение |
|---|---|
| `at`, `day`, `time_zone` | время; **день ученика** в его часовом поясе (вычисляется на устройстве) |
| `trainer` | `review` («Повторение»), `active` («Активно»), `nouns`, `verbs`, `adjectives`, `prepositions` |
| `mode`, `session_id` | режим тренажёра; одна сессия = один заход |
| `word`, `entry_id`, `card_id` | слово и ссылка на запись словаря / карточку |
| `checks` | что проверялось: `translation`, `article`, `plural`, `word_with_article`, `form` (+ `form`: `praeteritum` / `partizip2`), `conjugation` (+ `pronoun`, `tense`: `present` / `preteritum` / `perfekt` / `future`), `sentence` (предложение принято ИИ-тьютором), `adjective_ending` (+ рамка «тип артикля · падеж · род»), `preposition_case`, `recognition` / `recall` / `listening` / `spoken_production` |
| `prompt`, `answer`, `expected` | задание, ответ ученика, правильный ответ |
| `outcome` | `correct` · `typo` · `incorrect` · `dont_know` · `skipped` (пустой ответ) · `technical` · `self_rated` |
| `attempt_no`, `first_try` | 1 — первый показ в сессии; 2+ — круг «повторить ошибки» |
| `hint_used`, `answer_shown` | подсказка; подсмотренный ответ (такой ответ не считается успехом с первой попытки) |
| `self_grade` | только для `self_rated`: 1 «не помню» … 4 «легко» — **никогда не считается проверенным правильным ответом** |

«Активно» пишет два события: автоматическую проверку набранного или распознанного ответа и самооценку.

## Инструменты

### `get_training_summary`

```json
{ "period": "today" }
{ "period": "last_7_days", "trainer": "verbs" }
{ "from": "2026-10-01", "to": "2026-10-03", "checks": "conjugation" }
```

Возвращает:
- `totals` — заданий, уникальных слов, проверенных ответов, верных, опечаток, ошибок, «не знаю»,
  пропусков, технических ошибок, точность, `first_try_correct` и `first_try_accuracy_percent`,
  подсказки, подсмотренные ответы, `corrected_after_error`;
- `by_trainer`, `by_check` — то же по тренажёрам и по виду проверки;
- `flashcard_self_ratings` — самооценки «Повторения» отдельно;
- `difficult.articles / plurals / verb_forms / conjugations / adjective_endings / preposition_cases /
  translations` — конкретные ошибки: слово, форма, местоимение и время, ответ ученика, правильный ответ,
  была ли это первая попытка;
- `repeated_errors` — один и тот же пункт неверно 2+ раза; `fixed_later` — исправлен ли потом;
- `trend_by_day` — динамика по дням;
- `word_knowledge` — по каждому слову отдельно: перевод, артикль, форма глагола, спряжение,
  употребление в предложении. Один показатель не заменяет другой.

«Сегодня» — это сегодня в часовом поясе ученика: берётся из его последнего события или из параметра
`time_zone`.

### `get_training_history`

Фильтры: `period` / `from` / `to`, `trainer`, `checks`, `word`, `outcome`, `only_errors`. Пагинация:
`limit` (до 200), `offset`, в ответе `next_offset`.

### `get_learning_gaps`

Дополнен полем `trainer_errors`: ошибки тренажёров за две недели с источником (`trainer:nouns`,
`trainer:verbs`…). Карточки автоматически не создаются: материал выбираете вы, наличие проверяете через
`check_dictionary_words`.

## Синхронизация

Ответ сначала попадает в очередь в браузере (отдельно для каждого пользователя), затем уходит пачками в
`POST /api/training-events`: через 2,5 с после ответа, при восстановлении сети, при сворачивании страницы и
при входе в приложение. Из очереди событие удаляется только после подтверждения сервера. Уникальный
`client_event_id` делает повторную отправку безопасной: в ответе `duplicates`, дублей в базе нет.
Проверено.

## Интервалы SRS (`interval_days: 2 589 949`)

**Причина — ошибка расчёта**, не единицы и не вывод. До 2026-10-02 у SM-2 не было потолка, а оценка
карточки раньше срока (тренировка пачкой) умножала полный запланированный интервал, как будто срок честно
выдержан. У 82 карточек за ~10 дней набралось 7–12 «повторений» с ease до 4,15, отсюда интервалы до
2,6 млн дней (срок — 9117 год). Исправлено в `lib/srs/sm2.ts`: потолок 3650 дней; при досрочном повторе
интервал растёт от реально прошедшего времени и не уменьшается; «Легко» до срока не повышает ease. Данные
82 карточек без решения владельца не изменялись.

## Переподключение агента

Список инструментов клиент запоминает при подключении. Версия сервера (`MCP_SERVER_VERSION`, сейчас
`1.8.0`) меняется вместе с набором инструментов. Если агент не видит инструмент из
`https://aibook-liart.vercel.app/api/mcp-version`, переподключите коннектор.
